# Data sources and availability

Code and generated research data have different distribution requirements. Store raw references, processed sequence inputs, checkpoints, result tables and figures in the project directories described by [the reproduction guide](MANUSCRIPT_REPRODUCTION.md), outside the Git checkout.

| Resource | Source / version | Included in this repository |
| --- | --- | --- |
| Human protein-coding transcripts | [GENCODE release 40](https://www.gencodegenes.org/human/release_40.html), GRCh38.p13 | Download/preprocessing code, expected counts and hashes; FASTA downloaded separately |
| COSMIC SBS profiles | v3.3.1; GRCh37 profile used by the reference campaigns | Tables packaged in the separate Sinabro repository; profile hashes recorded per run |
| Bat genome and gene annotations | [Bat1K Pilot Project](https://bds.mpi-cbg.de/hillerlab/Bat1KPilotProject/), HLmolMol2 and HLmyoMyo6 | URL/checksum manifest, extraction code and frozen transcript IDs; large genomes downloaded separately |
| Six bat APOBEC motif preferences | Experimental C-to-T motif-average workbook | Original workbook and documented conversion code under `06_Bat_genome/experimental_apobec/` |
| Original supporting tables | `00_supporting_information/` | Preserved manuscript workbooks |
| S11 historical estimates | 3,740 paired transcript estimates | Compressed estimate table and source manifest under `07_manuscript_validation/source_data/` |
| BRCA1 coordinate reference | GENCODE v40 CDS/stop-codon features | Small coordinate/provenance JSON and independent reference validation; no full genome/GTF transfer needed for the standard job |
| Observed BRCA1 variants | [COSMIC v101 MutantCensus](https://cancer.sanger.ac.uk/cosmic/download/cosmic/v101/mutantcensus) and [Classification](https://cancer.sanger.ac.uk/cosmic/download/cosmic/v101/classification), GRCh38 | Download/processing code and official checksums; observation tables require separate account-authorized retrieval |
| Full checkpoints, tables and figures | Generated by the workflows | Kept outside Git with their manifests and audits |

## References and prepared inputs

[Human preparation](01_data_downloading_and_preprocessing/README.md) defines the CDS-plus sequence and historical rejection rules. [Bat preparation](06_Bat_genome/HPC_REPRODUCTION.md) uses the frozen transcript populations and source snapshots rather than substituting a newer annotation. Download manifests distinguish configured/preserved hashes from independently supplied publisher checksums.

The experimental source workbook is included with project-owner authorization. Conversion uses the 16 motif-average values per enzyme, normalized as per-opportunity weights; exact historical probability CSVs were not recovered. Raw assay reads and the upstream read-processing workflow are not included.

The archived S11 table contains historical simulation estimates and transcript identifiers, not new corrected-package trajectories. The supporting workbooks remain original source tables and should not be relabelled as newly calculated results.

## COSMIC observation access

Use the [download instructions](01_data_downloading_and_preprocessing/COSMIC_VARIANTS.md), then [breast selection and coordinate mapping](01_data_downloading_and_preprocessing/COSMIC_BREAST_VARIANTS.md). Registration/account access and the provider's terms apply. No account credentials, signed download URLs, raw COSMIC mutation tables or processed restricted observation tables are included here. v101 is the declared reconstruction release; its identity with the original historical release is not established.

## Preserve a campaign

Retain raw-file hashes, prepared-input manifests, full output audits, exported tables and final artwork with each calculation. Record both repository commits and the resolved Conda environment. A source-code checkout is not a checkpoint archive. Generated data are excluded through `.gitignore`; the absence of large results from Git does not mean they are bundled with a software release. Add any future public dataset/archive accession only when that archive has actually been deposited.
